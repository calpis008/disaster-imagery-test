# 航測及遙測分署影像探索平台 — 使用者操作手冊

> 適用對象：初次使用本平台的一般使用者
> 支援瀏覽器：Chrome（建議）、Edge、Firefox 最新版

---

## 1. 平台簡介

本平台提供三種影像資料的線上瀏覽與比對：

| 站台 | 影像內容 | 特色 |
|------|----------|------|
| **DMC III 航攝影像** | 分署 DMC III 航空攝影影像 | 高解析度航照，同一天常有多幅影像涵蓋同一地點 |
| **福衛八號影像** | 福爾摩沙衛星八號影像 | 台灣自主衛星影像 |
| **Sentinel-2** | 歐洲太空總署 Sentinel-2 衛星影像 | 全球涵蓋、10 公尺解析度、更新頻繁 |

畫面最上方的**分署頁首**有三個按鈕，隨時可切換不同站台。

## 3. 基本操作

### 3.1 移動與縮放地圖
- **平移**：滑鼠左鍵按住拖曳
- **縮放**：滑鼠滾輪，或左側工具列 `＋`/`－`
- **搜尋地點**：左側工具列 🔍，輸入地名或座標
- **1:1**：以影像原始解析度顯示（左側工具列 `1:1` 按鈕）

> 💡 **重要觀念**：系統顯示的影像永遠以**地圖畫面中心點**為準。
> 平移地圖後，日曆與場景資訊會自動更新為新中心點可用的影像。

### 3.2 選擇日期
1. 底部中央的**日曆**顯示目前中心點有影像的日期（亮起的方格）
2. 點選任一亮起的方格即載入該日期影像
3. 上方下拉選單可切換「過去 12 個月」或特定年份
4. **雲量過濾**（CLOUD 滑桿）：拖曳可隱藏雲量過高的日期

### 3.3 查看場景資訊
右下角「SCENE INFORMATION」面板顯示目前日期在中心點的**所有**影像：

- 標題後方數字（例：`(4)`）代表共有 4 幅影像涵蓋中心點
- 每幅顯示：場景 ID、影像衛星、拍攝時間、雲量
- 幅數較多時可用**滾輪捲動**查看全部

## 4. 四種模式說明

### 4.1 EXPLORE（探索）— 預設模式

點選 EXPLORE 後可再選兩種子模式：

**DYNAMIC（動態視圖）**
- 不需選日期，系統自動優先顯示**最新、雲量最少**的影像並融合為完整鑲嵌圖
- 適合快速瀏覽大範圍現況
- 平移縮放時，地圖持續自動更新為最佳可用影像

**FIND A SCENE（尋找場景）**
- 用日曆選擇特定日期
- 地圖同時顯示該日期涵蓋中心點的**所有影像**（自動鑲嵌）
- 右側面板列出每一幅的詳細資訊

### 4.2 SWIPE（捲簾比對）

比較同一地點**兩個不同日期**的影像：

1. 點選 SWIPE 模式
2. 左側選單選「LEFT」，用日曆選第一個日期
3. 切換「RIGHT」，選第二個日期
4. 地圖中央出現**垂直分隔線**，左右各顯示一個日期的影像
5. **拖曳分隔線**左右滑動，直接比對變化（如災前災後、植生變化）

### 4.3 ANIMATE（動畫）

將多個日期的影像串成時序動畫：

1. 點選 ANIMATE 模式
2. 點「＋ ADD A SCENE」新增一幀，用日曆指定日期；重複新增多幀（至少 2 幀）
3. 點**播放鍵 ▶** 開始播放（首次載入需數秒）
4. 播放中畫面左上顯示目前幀的日期
5. 控制項（畫面右上）：
   - **Speed 滑桿**：調整播放速度
   - **⬇ 下載按鈕**：將動畫存成影片檔
     - 點擊後選擇解析度（1920×1080 / 1080×720 / 1080×1080 / 目前視窗大小）
     - Chrome 瀏覽器輸出 **MP4**；其他瀏覽器輸出 WebM 格式
     - 顯示「產生影片中…」，完成後自動下載
   - **⏸ / ▶**：暫停與繼續
   - **✕**：結束動畫回到編輯狀態

## 6. 常見問題（FAQ）

**Q1：日曆上都沒有亮起的日期？**
中心點目前位置沒有影像。請平移地圖到有影像涵蓋的區域（台灣本島範圍），或切換年份查看。

**Q2：選了日期但地圖沒有影像？**
確認地圖中心點（畫面正中央）是否在影像涵蓋範圍內；平移後系統會自動重新比對。

**Q3：動畫播放鍵是灰色的？**
至少要新增 2 個有指定日期的場景才能播放。

**Q4：下載的影片打不開？**
非 Chrome 瀏覽器會輸出 WebM 格式，建議用 Chrome 取得 MP4；WebM 可用 VLC 播放器開啟。

**Q5：畫面顯示的影像模糊？**
點左側 `1:1` 以原始解析度檢視；過度放大超過影像解析度時會模糊，屬正常現象。

**Q6：SWIPE 模式下拖不動分隔線？**
請直接按住分隔線中央的圓形把手拖曳，不要點地圖其他位置。
