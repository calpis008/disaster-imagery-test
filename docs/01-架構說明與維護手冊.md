## 1. 專案背景與來源

本專案 fork 自 Esri Living Atlas 團隊的開源專案
[Esri/imagery-explorer-apps](https://github.com/Esri/imagery-explorer-apps)（Apache 2.0 授權），
在原有的多個影像探索應用基礎上，為 **農業部林業及自然保育署 航測及遙測分署（ASRS）** 新增了三個客製化應用：

| 應用 | 路徑 | 資料來源 |
|------|------|----------|
| **DMC III 航攝影像探索** | `/dmcexplorer` | 分署自有 DMC III 航空攝影影像（ArcGIS Enterprise ImageServer） |
| **福衛八號影像探索** | `/fs8explorer` | 福衛八號（FORMOSAT-8）衛星影像（ArcGIS Enterprise ImageServer） |
| **Sentinel-2 包裝頁面** | `/sentinel2explorer` | Esri Living Atlas 公開 Sentinel-2 服務（iframe 內嵌） |

原始專案其餘應用（Landsat、Sentinel-1、Land Cover 等）程式碼仍保留在 repo 中，
但**不在分署部署範圍內**，詳見[第 15 節](#15-已知限制與客製化技術決策)之冗餘模組清單。

## 3. Monorepo 多應用架構

本 repo 是「一個程式碼庫、多個獨立應用」的架構。每個應用：

- 有自己的進入點：`src/<app-name>/index.tsx`
- 共用 `src/shared/` 之元件、store、服務、工具
- 由 webpack 以 `--env app=<config.json 中的 key>` 決定建置哪個應用
- 應用清單與標題、路徑定義在 **`src/config.json`**

```
webpack --mode production --env app=dmcexplorer --env envFileName=.env
   │
   ├─ 讀取 src/config.json 的 "dmcexplorer" 設定（title / pathname）
   ├─ 讀取 .env 的環境變數（服務 URL、App ID）注入為全域常數
   └─ 進入點 src/dmc-explorer/index.tsx → 輸出 dist/dmcexplorer/
```

### 分署使用的三個建置指令

```bash
npm run build:dmc        # DMC III → dist/dmcexplorer/
npm run build:fs8        # 福衛八號 → dist/fs8explorer/
# Sentinel-2 包裝頁為 CI 內嵌 HTML，見 .github/workflows/deploy.yml
```

## 5. 核心架構：Redux 狀態管理

所有應用共用 `src/shared/store/` 的 slices。與分署應用最相關的是 **`ImageryScene`** slice：

### 5.1 ImageryScene slice 關鍵狀態

| 狀態 | 型別 | 說明 |
|------|------|------|
| `mode` | `AppMode` | 目前模式：`dynamic` / `find a scene` / `swipe` / `animate` / `analysis` |
| `availableImageryScenes` | `ImageryScene[]` | **地圖中心點**目前可用的所有場景（含重疊多幅） |
| `queryParams4MainScene` | `QueryParams4ImageryScene` | 主場景查詢參數（日期、objectId、raster function） |
| `queryParams4SecondaryScene` | 同上 | SWIPE 模式右側場景參數 |
| `queryParamsList` | `{[id]: QueryParams…}` | ANIMATE 模式的多幀清單 |
| `shouldForceSceneReselection` | `boolean` | 為 `true` 時地圖移動後重新選擇對應中心點的場景 |

### 5.2 資料流（以 DMC 為例）

```
使用者平移地圖
  → useQueryAvailableDMCScenes hook 觸發
  → dispatch queryAvailableDMCScenes thunk (src/shared/store/DMC/thunks.ts)
      → 向 ImageServer /query 查詢包含中心點的所有場景
      → dispatch shouldForceSceneReselectionUpdated(true)   ← 分署客製：確保場景跟隨中心點
      → dispatch availableImageryScenesUpdated(scenes)
  → useFindSelectedSceneByDate 依日期重新選擇場景
  → DMCLayer / SceneInfoContainer 依 availableScenes 重新渲染
```

**維護重點**：`shouldForceSceneReselectionUpdated(true)` 這行是分署客製，
若移除會回到上游行為（平移地圖後仍鎖定舊場景），造成「顯示的影像不在畫面中心」的問題。

## 6. 核心架構：ArcGIS 影像圖層機制

### 6.1 MosaicRule 三種用法

ImageServer 用 **MosaicRule** 決定回傳哪些影像、如何疊合。本專案用到三種：

```typescript
// (a) 屬性排序 mosaic —— DYNAMIC 模式（顯示全區最佳影像，同 Sentinel-2）
new MosaicRule({
    method: 'attribute', operation: 'first',
    sortField: 'ZOrder', sortValue: '0', ascending: true,
});

// (b) 多場景鎖定 mosaic —— EXPLORE / SWIPE / ANIMATE（分署客製核心）
//     把選定日期在中心點的「所有重疊場景」一次全部顯示
new MosaicRule({
    method: 'lock-raster',
    lockRasterIds: [101, 102, 103],          // 該日期所有場景的 objectId
    where: 'objectid in (101,102,103)',
});

// (c) 單場景鎖定 —— 原上游行為，現僅少數 fallback 情境使用
new MosaicRule({ method: 'lock-raster', lockRasterIds: [101], … });
```

### 6.2 多場景 objectIds 的取得方式

各模式一致的邏輯——由 `availableScenes` 用 `formattedAcquisitionDate` 過濾：

```typescript
const objectIds = availableScenes
    .filter((s) => s.formattedAcquisitionDate === acquisitionDate)
    .map((s) => s.objectId);
```

此邏輯出現在三個地方，修改時須同步：

| 檔案 | 模式 |
|------|------|
| `DMCLayer.tsx` | EXPLORE（find a scene）、ANIMATE 預覽 |
| `DMCSwipeComponent.tsx` | SWIPE 左右兩側 |
| `useDMCMediaLayerImageElement.tsx` | ANIMATE 播放幀匯出 |

### 6.3 各模式圖層可見性矩陣（DMCLayer.getVisible）

| 模式 | DMCLayer 可見？ | Mosaic 規則 |
|------|----------------|-------------|
| `dynamic` | ✅ 永遠可見 | (a) 屬性排序 |
| `find a scene` | 有場景時可見 | (b) 多場景鎖定 |
| `swipe` | ❌ 隱藏（由 DMCSwipeComponent 自建左右圖層） | — |
| `animate` | 未播放時可見 | (b) 多場景鎖定 |
| `analysis` | （已從 UI 移除此模式） | — |

## 7. DMC Explorer 詳細說明

### 7.1 元件關係圖

```
Layout.tsx（底部面板）
├── AgencyHeader          ← 分署 logo 頁首 + 應用切換
├── AppHeader             ← 應用標題列
├── ModeSelector          ← modesToHide={['analysis']}：隱藏分析模式
├── (dynamic 模式) DMCDynamicModeInfo   ← 中文說明，無日曆
├── (其他模式)   Calendar + CloudFilter ← 日期選擇 + 雲量過濾
└── SceneInfoContainer    ← 右側場景詮釋清單（寬 320px，maxHeight 240px 可捲動）

Map.tsx（地圖）
├── FootPrintOfSelectedScene  ← 選定場景外框
├── GroupLayer
│   ├── DMCLayer              ← 主影像圖層
│   └── DMCAnimationLayer     ← 動畫層（MediaLayer + 控制 UI）
├── DMCSwipeComponent         ← SWIPE 左右圖層 + 分割 widget
├── HillshadeLayer            ← 地形陰影底圖
└── MapActionButtonGroup      ← 1:1 縮放、截圖等
```

### 7.2 ANIMATE 動畫與 MP4 下載（分署客製）

上游的動畫 MP4 下載依賴 `@vannizhang/images-to-video-converter-client`，
該套件有 **hostname 白名單檢查（僅限 arcgis.com / esri.com）** 且依賴 Esri 私有 Azure 編碼後端，
在分署網域**無法使用**。因此客製方案為：

1. `useDMCMediaLayerImageElement`：每幀以 `exportImage`（多 objectIds 鎖定）取得該日期完整 mosaic 圖
2. `createAnimationVideo.ts`：以瀏覽器原生 **`canvas.captureStream()` + `MediaRecorder`** 錄製
   - Chrome 121+ 輸出 **MP4**；其他瀏覽器 fallback **WebM**
   - 全程在使用者瀏覽器內完成，**不經任何外部服務**（資安優勢）
3. `DMCDownloadButton.tsx`：解析度選單（1920×1080 / 1080×720 / 1080×1080 / 目前視窗）

### 7.3 場景資訊面板（SceneInfoContainer）

- 顯示選定日期在中心點的**所有**場景（幅 1/N、2/N…）
- 每幅顯示：場景 ID、影像衛星、拍攝時間、雲量
- 由 `availableScenes` 前端過濾，**不需額外 API 呼叫**

## 8. FS8 Explorer 詳細說明

FS8 結構與 DMC 相同但更精簡：

- `FS8Layer.tsx` 直接使用共用的 `ImageryLayerByObjectID`（單場景 + dynamic mosaic），
  未實作 DMC 的多場景 mosaic（衛星影像單景涵蓋範圍大，通常不需要）
- 若日後需要 FS8 也支援多場景顯示，可直接仿照 `DMCLayer.tsx` 實作
- 服務設定：`src/shared/services/fs8/config.ts`

## 9. Sentinel-2 包裝頁面

Sentinel-2 **不在本 repo 建置**，而是：

- 部署版：CI（`deploy.yml`）產生 `dist/sentinel2explorer/index.html`，
  以 **iframe 內嵌 Esri 公開版 Sentinel-2 Explorer**，上方加上分署頁首（logo + 導覽按鈕）

修改 Sentinel-2 頁首時，**須同時修改 `deploy.yml` 內嵌 HTML 與 `sentinel2-local.html`** 兩處。

## 11. 建置與部署（CI/CD）

### 11.1 流程（`.github/workflows/deploy.yml`）

```
push 到 main
  → npm ci --ignore-scripts
  → 由 GitHub Secrets 產生 .env
  → npm run build:dmc  → dist/dmcexplorer/
  → npm run build:fs8  → dist/fs8explorer/
  → 產生 dist/index.html（跳轉至 DMC）
  → 產生 dist/sentinel2explorer/index.html（iframe 包裝頁）
  → cp public/logo.png dist/logo.png
  → 部署 dist/ 到 gh-pages 分支 → GitHub Pages
```

### 11.2 需設定的 GitHub Secrets

`DMC_EXPLORER_APP_ID`、`DMC_SERVICE_URL`、`FS8_EXPLORER_APP_ID`、`FS8_SERVICE_URL`、`ARCGIS_PORTAL_ROOT_URL`

### 11.3 常見 CI 失敗原因

| 症狀 | 原因 | 處理 |
|------|------|------|
| `Module not found: … logo.png` | `public/logo.png` 未 commit | `git add public/logo.png` |
| TypeScript 編譯錯誤 | `fork-ts-checker` 嚴格檢查 | 本機先跑 `npx tsc --noEmit` |
| 頁面白屏但 CI 綠燈 | Secrets 未設定，服務 URL 為空 | 檢查 repo Settings → Secrets |


## 13. 常見維護工作

### 13.1 更換影像服務 URL
1. 修改 GitHub Secrets 的 `DMC_SERVICE_URL` / `FS8_SERVICE_URL`
2. 本機 `.env` 同步修改
3. 若欄位名稱不同，修改 `src/shared/services/dmc|fs8/config.ts`

### 13.2 更換 logo
1. 覆蓋 `public/logo.png`（頁首高度固定 42px，建議等比寬度）
2. commit 後 CI 會自動複製到 `dist/logo.png`（Sentinel-2 頁使用相對路徑 `../logo.png`）

### 13.3 新增/隱藏功能模式
- `Layout.tsx` 的 `<ModeSelector modesToHide={['analysis']} />` 控制顯示哪些模式按鈕
- 目前 DMC 與 FS8 均隱藏 `analysis`（無多波段可分析）

### 13.4 調整場景資訊面板
- 寬度：`SceneInfoContainer.tsx` 的 `style={{ width: '320px' }}`
- 清單高度：`maxHeight: '240px'`

### 13.5 升級依賴
- `@arcgis/core` 大版本升級須詳測 MosaicRule / MediaLayer 行為
- React 大版本升級須同步 `@types/react`
- 升級後務必執行三個應用的完整手動測試（五種模式）

## 14. 資安注意事項

1. **機密管理**：服務 URL 含 server token，一律經 `.env`（本機）與 GitHub Secrets（CI），禁止硬編碼於程式（`config.ts` 中的 DEFAULT 值僅為 fallback，正式環境以環境變數覆蓋）。
2. **外部依賴呼叫面**：
   - ArcGIS ImageServer（edi.asrs.gov.tw）— 影像資料
   - Esri CDN（js.arcgis.com 字型/worker，若採 CDN 模式）
   - Esri 公開 Sentinel-2（僅 iframe 包裝頁）
   - MP4 產生**完全在瀏覽器本地執行**，無資料外流
3. **依賴掃描**：建議 CI 加入 `npm audit --production` 與 SBOM 比對（見 `02-SBOM軟體物料清單.md`）。
4. **`@vannizhang/*` 套件**：為 Esri 工程師個人 npm 套件，非官方組織帳號發佈，升級時應人工檢視 diff；其中 images-to-video 套件實際上已不被分署應用使用（見 15 節），可評估移除。
5. **npm overrides**：`package.json` 中 `"uuid": "^11.1.1"` 為修補傳遞依賴弱點所設，勿任意移除。
6. **安裝時**：CI 使用 `npm ci --ignore-scripts` 防止惡意 postinstall script。

### 15.2 重要技術決策記錄

| 決策 | 原因 |
|------|------|
| MP4 下載改用瀏覽器 MediaRecorder | 上游套件鎖 arcgis.com 網域 + 依賴 Esri 私有後端 |
| EXPLORE/SWIPE/ANIMATE 顯示多場景 mosaic | DMC 航照單幅涵蓋小，中心點常有多幅重疊，逐張切換不符作業需求 |
| 隱藏 ANALYZE 模式 | DMC/FS8 服務無多波段，光譜/指數分析無意義 |
| Sentinel-2 採 iframe 包裝而非自建 | 直接利用 Esri 公開版，免除服務代理與額度成本 |
| `shouldForceSceneReselection` 於 DMC thunk 強制開啟 | 使顯示場景永遠跟隨地圖中心點 |
| DYNAMIC 模式不顯示日曆 | 動態 mosaic 與日期選擇無關，比照 Sentinel-2 UX |

| 層面 | 評估事項 |
